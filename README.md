# ✈️ Airline Customer Satisfaction - Data Analysis Project

This project is based on airline customer data. I analyzed the data from start to end — from cleaning to machine learning.

---

## ✅ Steps I Followed

### 🔹 Step 1: Data Cleaning
- Removed missing values
- Checked data types and fixed them

### 🔹 Step 2: Exploratory Data Analysis (EDA)
I made graphs and understood the patterns:
- Most satisfied passengers travel in **Business Class**
- **Male passengers** are slightly more satisfied than females
- **Business travel type** has more satisfied customers than personal travel
- High **flight delays** lead to less satisfaction

### 🔹 Step 3: Grouping & Insights
- **Inflight Wifi**, **Cleanliness**, and **Online boarding** are top features for satisfaction
- People in **Business Class** gave higher ratings
- Customers with **less delay** are mostly satisfied
- **Top 5 destinations** have highest satisfaction ratings

### 🔹 Step 4: Machine Learning Model
- I trained a **Random Forest model** to predict satisfaction
- Model Accuracy: ~ `XX%` (90+)
- Most important features in the model:
  - Inflight Wifi
  - Seat Comfort
  - Cleanliness

## 🎯 Conclusion
This project helped me understand:
- How to clean and analyze real-world data
- How customer satisfaction depends on services and delays
- How to use ML to predict satisfaction for future customers
